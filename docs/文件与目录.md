# 文件与目录

← 回到 [README](../README.md)

## 仓库里有什么

| 路径 | 内容 |
|---|---|
| `tools\csgotool.py` | 主 CLI |
| `tools\pipe.py` | 文件管道传输层（`send` / `get_cvar` / `set_cvar`） |
| `tools\skins_catalog.py` | kgns 双语皮肤表解析 |
| `tools\bot_profiles.py` | `botprofile.db` 文本档解析（2187 个 profile） |
| `tools\bots_patch.py` | `bots patch` 的引擎：扫 profile 头行，改档位 / 删弱档 block / 换名，备份与还原都记账 |
| `tools\gamedir.py` | 游戏目录解析：环境变量 → settings.ini → 扫 Steam 库；不写死任何人的路径 |
| `tools\installer.py` | `install` 的引擎：下载、字节/SHA-256 校验、staging、备份、落地、还原 |
| `tools\build_exe.py` | 重打包两端 exe + 冒烟自检 + 打印 SHA-256 |
| `tools\shell_ui.py` | `shell` 的界面层（菜单、分页选择器、表单） |
| `tools\csgoclient.py` | 朋友端入口：只有 `socket` + `os.startfile`，没有任何写能力 |
| `tools\secret_scan.py` | 发布闸门：扫工作区 + 全部 git 对象 + 提交元数据里的标识，命中即非零退出 |
| `tools\fetch_includes.py` | 抓 SourceMod include 供本地编译 `.sp`（一次性工具） |
| `tools\src\` | **我们自己写的插件源码**（`lan_pipe.sp` / `lan_fix.sp`）；游戏 `addons\sourcemod\scripting\` 里那份只是部署结果，两边已核对为同一份哈希 |
| `release\plugins\` | 我们这两个插件的编译产物（`.smx`），`install` 直接装它们，用户不需要 spcomp |
| `configs\` | **我们写的 cfg 源文件**（`lan.cfg` / `bots_improved.cfg`）+ `components.json`（第三方组件的版本、URL、字节数、SHA-256、保留名单、首跑清单） |
| `docs\` | 详细操作文档，索引在 README |
| `THIRD_PARTY_NOTICES.md` | 哪些东西故意不打包、装的时候从哪来、各自什么许可 |
| `LICENSE` | GPL-3.0-or-later 全文 |
| `secrets.example.json` | `secret_scan.py` 要用的"我自己的标识"模板；复制成 `.secrets.json`（已 gitignore） |
| `csgotool.cmd` | 双击开循环版窗口（纯 ASCII，透传参数） |
| `.gitattributes` | 行尾策略：批处理 CRLF、`.py/.sp/.cfg/.md` LF、`backup/**` 与 `*.orig` 标 `-text` 禁止任何改写（备份文件的作用是按字节还原） |

## 生成在本机、不入库

| 路径 | 内容 |
|---|---|
| `lan\join-<IP>.cmd` | 给朋友双击的加入文件（里面有密码，所以不入库） |
| `exe\` `dist\` `build\` | PyInstaller 产物（重打包：`python tools\build_exe.py`） |
| `downloads\` | `install` 的下载缓存，都能按清单重下，且里面是别人的二进制 |
| `staging\` | 解压核对用的临时目录 |
| `settings.ini` | `gamedir --set` 写下的本机游戏目录，换台机器就该换值 |
| `.secrets.json` | 扫描器要查的"我自己的标识"，永远不入库 |
| `backup\install\<时间戳>\` | 一次 install 的现场：被替换下来的文件 + `report.json`，`uninstall --revert` 只按它行动 |
| `backup\bots\<时间戳>\` | 一次 `bots patch` 的现场：改写前的 `botprofile.db` + `report.json` |
| `backup\` 其余 | 我们自己插件的旧版本（`lan_fix.smx.1.0.5`）与 Valve 文件原件 |

**Valve 的游戏文件本体（`botprofile.db.orig`、`gameinfo.txt.orig`）、本机视频设置、以及上游没给
许可的文件都只留在本机**，被 `.gitignore` 排除；清单的 `skip` 与 `note` 字段写明了每一项的原因。

## 游戏目录里的运行时文件

工具与插件之间靠文件通信（这台 build 没有 connectionless RCON）：

| 路径 | 作用 |
|---|---|
| `...\csgo\addons\sourcemod\scripting\lan_pipe.sp` | 文件管道插件（每 `sm_lanpipe_interval` 秒读一行执行一行） |
| `...\csgo\addons\sourcemod\scripting\lan_fix.sp` | 皮肤/手套实写 + bot 内存探针 + 自动发枪补钱 |
| `...\csgo\addons\sourcemod\data\lan_pipe.txt` | 命令入口（写一行执行一行，执行完清空） |
| `...\csgo\addons\sourcemod\data\lan_exec.log` | 管道执行结果 |
| `...\csgo\addons\sourcemod\data\lan_fix.log` | 插件机器可读输出（皮肤 dump、botmem、autoshow） |
| `...\csgo\addons\sourcemod\logs\errors_YYYYMMDD.log` | SourceMod 错误日志，按天命名 |
| `...\csgo\addons\sourcemod\data\sqlite\sourcemod-local.sq3` | kgns 的皮肤表，主键是 SteamID |
| `...\csgo\cfg\lan.cfg` / `bots_improved.cfg` | 联机配置 / bot 与回合参数 |

**绝对不要把轮询器挂在管道上 while 服务器没跑**：`lan_pipe.txt` 只有插件会清空，
一整晚的探测会在里面堆几千行，地图一加载全被执行，把第一次真正的验证输出埋掉。
